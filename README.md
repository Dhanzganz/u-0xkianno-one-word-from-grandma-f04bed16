Exactly one word: the word a grandma would text about AI.

Output path: `/output/entry.txt` (set `OUTPUT_DIR` to override it for local runs).

The entry program (`main.ts`) writes a single word — **Marvelous** — to
`/output/entry.txt`, and nothing else. Warm, a little baffled, and delighted:
the exact word a grandma types when her grandchild shows her what AI can do.

## Run

```sh
node main.ts
```

This writes `Marvelous` (9 characters, one word, no trailing newline) to
`/output/entry.txt`.
